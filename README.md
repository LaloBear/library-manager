# Library Manager

A Python command-line application for managing a collection of books. Built to practice object-oriented programming, file handling, and JSON data storage.

## Features
- Add and remove books
- Search for books by title or author
- Check out and return books
- Display available and checked-out books
- Sort books alphabetically by title
- Prevent duplicate book titles
- Save and load book data using JSON

## Technologies
- Python
- JSON
- Object-Oriented Programming (OOP)

## How to Run
1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   ```bash
   python3 library.py
   ```

## Project Structure
- `book.py` — Defines the Book class.
- `library_manager.py` — Handles library operations and data storage.
- `library.py` — Provides the interactive menu.
- `books.json` — Stores saved book information.
